# Banque SQL — 400 exercices

## Présentation du projet

Ce projet a pour objectif de construire et documenter progressivement une base de données bancaire avec MySQL.

La base sera développée avec Mysql. Chaque étape fera l'objet d'un script SQL, d'explications techniques et de vérifications.

## Objectifs pédagogiques

- Comprendre la création et l'organisation d'une base de données relationnelle.
- Concevoir les tables et leurs relations.
- Maîtriser les clés primaires, les clés étrangères et les contraintes.
- Charger et vérifier les données.
- Étudier les index, les vues, les procédures stockées, les fonctions et les triggers.
- Résoudre progressivement 400 exercices SQL.
- Utiliser Git et GitHub pour versionner et présenter le travail.

## Environnement technique

- Système : Windows
- SGBD : MySQL 8.0.46
- Outil SQL : MySQL Workbench
- Gestion de versions : Git
- Hébergement du code : GitHub

## Organisation du dépôt

- `docs/` : documentation et suivi de progression.
- `sql/01_creation/` : création de la base de données.
- `sql/02_tables/` : scripts de création des tables.
- `sql/03_donnees/` : chargement des données.
- `sql/04_index/` : index.
- `sql/05_views/` : vues.
- `sql/06_procedures/` : procédures stockées.
- `sql/07_functions/` : fonctions.
- `sql/08_triggers/` : triggers.
- `sql/09_exercices/` : exercices SQL.

## Méthode de travail

Chaque objet sera étudié individuellement : objectif, script SQL, explication des choix techniques, tests et documentation.

Les étapes seront validées progressivement. Les éléments non encore réalisés seront indiqués comme étant en cours ou à faire.
